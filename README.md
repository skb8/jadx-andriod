# JADX Android

Нативный Android-интерфейс для [JADX](https://github.com/skylot/jadx) 1.5.6. Декомпиляция выполняется на устройстве. Приложение рассчитано на Android 13 (API 33) и новее, ARM64 и x86-64.

## Что доступно

- Открытие нескольких документов через системный выбор файлов. Встроенные плагины читают APK, DEX, AAB, APKM, APKS, XAPK, JAR, CLASS, AAR и SMALI.
- Навигация по пакетам, классам и ресурсам. Вкладки Java и Smali, подсветка Java, просмотр XML, таблиц ресурсов и изображений.
- Поиск по классам и декомпилированному коду с учётом регистра и регулярными выражениями. В меню символа доступны переход к объявлению, поиск использований, псевдонимы и комментарии. Для методов доступен просмотр базовых блоков CFG с переходами.
- Сохранение параметров проекта, экспорт исходников и ресурсов в ZIP, варианты JSON и Gradle. Файл проекта ссылается на выбранные документы Android. При переносе на другое устройство разрешения на документы выдаются заново.
- Импорт, включение, выключение и удаление плагинов. Параметры активных плагинов доступны в меню проекта.
- В меню «Среда Java» можно скачать и выбрать OpenJDK 17 или 21 для отдельного варианта экспорта через JADX CLI. Приложение проверяет SHA-256 архивов и запускает JNI в отдельном процессе Android. Интерактивный просмотр и экспорт с изменениями проекта выполняются через Android ART.

Работа продолжается над паритетом с JADX GUI. Smali-отладчик, граф вызовов, совместимость с настольным форматом проектов и расширения Swing пока отсутствуют. При экспорте через OpenJDK используются исходные файлы, выбранный режим, деобфускация и показ некорректного кода. Псевдонимы, комментарии и DEX-плагины применяются при обычном экспорте.

## Плагины

Android-плагин — архив ZIP, JAR или APK с `classes.dex` и файлом `jadx-android.properties` в корне. Точка входа реализует `jadx.api.plugins.JadxPlugin` и имеет публичный конструктор без аргументов. Зависимости плагина должны поддерживать Android и входить в его DEX. API ядра JADX доступен из приложения.

```properties
id=example-plugin
provider=org.example.jadx.ExamplePlugin
jadxVersion=1.5.6
```

Для адаптации плагина JVM его код и совместимые зависимости можно преобразовать в DEX с помощью D8. Идентификатор в дескрипторе должен совпадать с `getPluginInfo().getPluginId()`. Включённый плагин работает с правами приложения.

## Сборка

Нужны JDK 17, Android SDK 35, Build Tools 34.0.0 и NDK 27.2.12479018.

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

Debug APK находится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions публикует этот файл как артефакт `jadx-android-debug`.

Ядро и CLI поставляет [skylot/jadx](https://github.com/skylot/jadx). Сборки OpenJDK для Android поставляет [openjdk-android-hostcraft](https://github.com/Project-crafting/openjdk-android-hostcraft).
