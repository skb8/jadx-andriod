# JADX Android

Нативный Android-интерфейс для [JADX](https://github.com/skylot/jadx) 1.5.6. Декомпиляция и экспорт выполняются на устройстве в Android ART. Приложение рассчитано на Android 13 (API 33) и новее.

## Что доступно

- Открытие нескольких документов через системный выбор файлов. Встроенные плагины читают APK, DEX, AAB, APKM, APKS, XAPK, JAR, CLASS, AAR и SMALI.
- Навигация по пакетам, классам и ресурсам. Вкладки Java и Smali, подсветка Java, просмотр XML, таблиц ресурсов и изображений.
- Путь к папке можно открыть по частям. При возврате из файла и переключении между классами и ресурсами сохраняются папка и позиция списка.
- Поиск по классам и декомпилированному коду с учётом регистра и регулярными выражениями. В меню символа доступны переход к объявлению, поиск использований, псевдонимы и комментарии. Для методов доступен просмотр базовых блоков CFG с переходами и навигация по графу вызовов.
- Сохранение параметров проекта, экспорт исходников и ресурсов в ZIP, варианты JSON и Gradle. Файл проекта ссылается на выбранные документы Android. При переносе на другое устройство разрешения на документы выдаются заново.
- Импорт, включение, выключение и удаление плагинов. Параметры активных плагинов доступны в меню проекта.

Работа продолжается над паритетом с JADX GUI. Smali-отладчик, совместимость с настольным форматом проектов и расширения Swing пока отсутствуют.

## Плагины

В меню «Плагины» доступны список встроенных модулей, импорт и управление установленными плагинами. Параметры активных плагинов доступны при открытом проекте.

| Вид | Поддержка |
| --- | --- |
| Встроенные модули | DEX/APK, Java-байткод (JAR, CLASS, AAR), Smali, AAB, APKS, APKM, XAPK и модуль маппингов имён. Выбор отдельного файла маппингов в Android-интерфейсе пока отсутствует |
| Подключаемый плагин Android | ZIP, JAR или APK с `classes.dex` и `jadx-android.properties` в корне |
| Обычный JVM-плагин с `.class` | Требует преобразования в DEX и проверки зависимостей |
| Расширения интерфейса JADX GUI на Swing | Требуют переноса интерфейса на Android |

Точка входа подключаемого плагина реализует `jadx.api.plugins.JadxPlugin` и имеет публичный конструктор без аргументов. Идентификатор в дескрипторе должен совпадать с `getPluginInfo().getPluginId()`. Дескриптор указывает версию ядра приложения.

```properties
id=example-plugin
provider=org.example.jadx.ExamplePlugin
jadxVersion=1.5.6
```

Поддержку можно расширять на ART. Для плагина, который добавляет входной формат, обработчик ресурсов или проход декомпиляции, соберите код под API ядра JADX 1.5.6 и преобразуйте его вместе с Android-совместимыми зависимостями в DEX с помощью [D8](https://developer.android.com/tools/d8). Добавьте в архив дескриптор и необходимые ресурсы плагина. Само ядро JADX предоставляет приложение. Плагинам, которые используют API настольного интерфейса, понадобятся отдельные Android-экраны и соответствующие точки расширения приложения. [Руководство по API плагинов JADX](https://github.com/skylot/jadx/wiki/Jadx-plugins-guide).

Импортированный плагин включается вручную и при включении получает права приложения.

## Сборка

Нужны JDK 17, Android SDK 35 и Build Tools 35.0.0.

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

Debug APK находится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions публикует этот файл как артефакт `jadx-android-debug`.

Ядро поставляет [skylot/jadx](https://github.com/skylot/jadx).
